Mawiblah diagnostic letter

Every variable Mawiblah supports appears below exactly once, wrapped in a marker element that names it. After a render, no marker may still contain its own token: whatever is left over is a variable that was not replaced, and the marker says which.

Shortcodes

  • [mawiblah_title]
  • [mawiblah_content]
  • [mawiblah_website_url]
  • [mawiblah_logo_alt]
  • [mawiblah_logo_src]
  • [mawiblah_social_profiles]
  • [mawiblah_newest_articles_title]
  • [mawiblah_newest_articles_paragraph]
  • [mawiblah_newest_articles count="3"]
  • [mawiblah_end_title]
  • [mawiblah_end_content]
  • [mawiblah_unsubscribe]
  • [mawiblah_new_posts_since_last_sent]
  • [mawiblah_subscribe_form]

Placeholders

  • {campaignHash}
  • {subscriberHash}
  • {email}
  • %7BcampaignHash%7D
  • %7BsubscriberHash%7D
  • %7Bemail%7D
